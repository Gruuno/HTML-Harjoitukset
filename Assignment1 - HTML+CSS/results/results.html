Fonts

The fonts used on this website are from Google Fonts:

  • JetBrains Mono - Käytetty normaalissa tekstissä ja kappaleissa.
  • Pixelify Sans - Käytetty otsikoissa, navigaatiossa ja painikkeissa.

Font styling in CSS:

  body {
    font-family: 'JetBrains Mono', monospace;
  }

  h1, h2, h3,
  header > a,
  nav a,
  .hero-link {
      font-family: 'Pixelify Sans', sans-serif;
  }
>
